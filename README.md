# python03

42 Heilbronn — Python module 03: data structures and generators.

Game-themed exercises covering the built-in collection types, comprehensions,
and command-line arguments.

| | Topic |
|---|---|
| `ex00` | `sys.argv` — argument count and iteration |
| `ex01` | Lists — parsing argv into ints, aggregate statistics, skipping invalid input |
| `ex02` | Tuples — parsing and validating an `x,y,z` triplet, retrying until valid |
| `ex03` | Sets — `union`, `intersection` and `difference` across four players' achievements |
| `ex04` | Dicts — building an inventory from `item:quantity` arguments with duplicate and range checks |
| `ex05` | Generators — `yield`, an infinite event stream consumed with `next()`, and a second generator that drains a list |
| `ex06` | List and dict comprehensions with conditional filtering |

## Running

```
python3 ex01/ft_score_analytics.py 100 250 40
python3 ex04/ft_inventory_system.py sword:1 potion:5
```
